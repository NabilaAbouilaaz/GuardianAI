# 🛡️ GuardianAI

Enterprise-grade cybersecurity platform for automated malware analysis and threat detection.

## 🚀 Tech Stack
* **Backend:** Spring Boot (Java 17), Spring Data JPA, PostgreSQL, Flyway, Spring Security
* **Frontend:** Angular, Tailwind CSS
* **AI Engine:** Integrated Threat Analysis Engine
